# форма. — сайт дизайн-студии

Готовый адаптивный сайт на **Next.js 16, React 19, TypeScript и Tailwind CSS 4**. Русский интерфейс, собственные SVG-иллюстрации, локальный шрифт Manrope, анимации и мобильное меню. Внешние API, ключи и база данных не требуются.

## Открыть сайт через интернет

GitHub хранит исходные файлы. GitHub Pages размещает собранный сайт в интернете, чтобы его можно было открыть обычной ссылкой. Перенаправлять порты для этого не нужно.

В репозитории настроена автоматическая сборка и публикация через `.github/workflows/pages.yml`. Один раз владелец репозитория должен разрешить GitHub Pages:

1. Открыть [настройки Pages](https://github.com/scprintbase-collab/yoooo/settings/pages).
2. В блоке **Build and deployment** выбрать **Source → GitHub Actions**.
3. Открыть [Publish website](https://github.com/scprintbase-collab/yoooo/actions/workflows/pages.yml), нажать **Run workflow**, затем ещё раз **Run workflow**. Если предыдущий запуск уже закончился ошибкой из-за выключенного Pages, можно вместо этого открыть его и нажать **Re-run all jobs**.

После успешного завершения публикации сайт будет по адресу **https://scprintbase-collab.github.io/yoooo/**. Наличие ссылки в этом файле само по себе не означает, что публикация уже выполнена: её подтверждает зелёный успешный запуск `Publish website` и открывающаяся страница.

Дальнейшие изменения в ветке `main` будут публиковаться автоматически. Включать платные услуги и вводить ключи не требуется для публичного репозитория. Для приватного репозитория доступность Pages зависит от тарифа GitHub; менять видимость без согласия владельца не следует.

Статическую версию можно собрать вручную (Linux/macOS):

```bash
STATIC_EXPORT=true NEXT_PUBLIC_BASE_PATH=/yoooo npm run build
```

Готовый сайт появится в `out/`. `NEXT_PUBLIC_BASE_PATH` нужен только для размещения в подпапке `/yoooo`; обычный локальный запуск работает без него. Для другого хостинга можно использовать `STATIC_EXPORT=true npm run build` без подпапки.

## Запуск

Нужны Node.js **20.9 или новее** и npm. В облачной среде проект находится в `/workspace/yoooo`.

```bash
cd /workspace/yoooo
npm ci
npm run dev
```

На компьютере откройте `http://localhost:3000` в браузере. Если репозиторий скачан в другую папку, сначала перейдите в неё вместо `/workspace/yoooo`. Сервер слушает `0.0.0.0`, поэтому его можно открыть через перенаправленный порт 3000 в среде разработки. Команда `Ctrl+C` останавливает сервер.

Для просмотра с телефона в одной локальной сети используйте `http://<IP-адрес-компьютера>:3000`. Для интерактивности и hot reload в режиме разработки добавьте этот IP в `allowedDevOrigins` в `next.config.ts` и перезапустите сервер. Не добавляйте туда произвольные домены или общий wildcard. Локальные `localhost` и `127.0.0.1` уже поддерживаются.

## Проверки

```bash
npm run lint
npm run typecheck
npm run build
npm run test:e2e
```

Playwright проверяет десктопную и мобильную версии: загрузку изображений, отсутствие горизонтальной прокрутки, меню, карточки проектов, работу клавиатуры, валидацию формы и скачивание брифа. Сервер разработки запускается автоматически, если порт 3000 свободен.

В этой облачной среде используется системный Chromium. На своём компьютере, если Chromium не установлен, один раз выполните:

```bash
npx playwright install chromium
```

При необходимости путь к своему браузеру можно передать через переменную `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

## Production-сборка

```bash
npm run build
npm start
```

Production-сервер также использует порт 3000; перед его запуском остановите `npm run dev`. Другой порт можно указать так: `npm start -- --port 3001`.

## Структура

```text
app/
  layout.tsx                  # HTML, метаданные, шрифт
  page.tsx                    # Главная страница
  globals.css                 # Tailwind, тема, адаптивность, анимации
  icon.svg                    # Иконка сайта
  not-found.tsx               # Страница 404
components/
  studio.tsx                  # Шапка, первый экран, меню, о студии, бриф, подвал
  content-sections.tsx        # Проекты, услуги, процесс и карточки проектов
public/images/                # Оригинальные SVG-иллюстрации
tests/site.spec.ts            # Браузерные сценарии
playwright.config.ts          # Desktop/mobile и настройка Chromium
```

## Что работает

- Адаптивная вёрстка, включая экраны 320 px, и якорная навигация.
- Мобильное меню с поддержкой Escape.
- Диалоги проектов: блокировка прокрутки, фокус и закрытие с клавиатуры.
- Форма брифа с обязательными полями, проверкой email и скачиванием `.txt`.
- Плавное появление секций и декоративная анимация с поддержкой `prefers-reduced-motion`.
- Самостоятельная загрузка: шрифты и изображения не требуют сторонних сервисов.

## Перед публикацией реального сайта

Это концептуальная студия и демонстрационные проекты. Форма **не отправляет заявку и не сохраняет персональные данные**: она создаёт бриф на устройстве пользователя. Для настоящих заявок потребуется отдельно подключить серверную отправку через выбранную почту или CRM и добавить политику обработки данных.

Замените название, проекты и тексты на свои. Адрес сайта для метаданных по умолчанию — `https://scprintbase-collab.github.io/yoooo/`; его можно заменить через `NEXT_PUBLIC_SITE_URL`. В `app/layout.tsx` включите индексацию, если сайт готов к продвижению: сейчас для демо указан `robots: { index: false, follow: false }`.

Цвета находятся в блоке `@theme` файла `app/globals.css`. Данные проектов и услуг — в начале `components/content-sections.tsx`.
